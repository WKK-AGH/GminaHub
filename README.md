# E-Sesja: Cyfrowa RadaGminy

E-Sesja to platforma wspierająca cyfrowe zarządzanie pracą rady gminy. System
umożliwia organizację spotkań, tworzenie i głosowanie nad projektami uchwał oraz
przechowywanie dokumentów radnych w bezpiecznym środowisku online.

## Opis

Projekt ma na celu usprawnienie procesu podejmowania decyzji w jednostkach
samorządu terytorialnego poprzez cyfrową obsługę sesji rady gminy. Dzięki
aplikacji radni i urzędnicy mogą przygotowywać porządek obrad, wymieniać
materiały oraz prowadzić głosowania zdalnie.

## Funkcjonalności

- zarządzanie sesjami i porządkiem obrad
- przygotowywanie projektów uchwał i wniosków
- elektroniczne głosowania dla radnych
- przeglądanie historii głosowań i archiwum dokumentów
- bezpieczny dostęp dla członków rady i administracji

## Instalacja

1. Sklonuj repozytorium:

    ```bash
    git clone https://github.com/WKK-AGH/GminaHub
    ```

2. Przejdź do katalogu projektu:

    ```bash
    cd GminaHub
    ```

3. Zainstaluj zależności:

    ```bash
    npm install
    ```

## Użytkowanie

1. Uruchom aplikację lokalnie:

    ```bash
    npm start
    ```

2. Otwórz przeglądarkę i przejdź pod adres wskazany w konsoli.
